# English Grammar Hub

Интерактивный сайт для изучения английской грамматики. Проект создан в учебных целях для портфолио frontend-разработчика.

## 🚀 Технологии

- **React 19** + **TypeScript** — типизированная разработка
- **Vite** — сборка и dev-сервер
- **React Router** — клиентский роутинг
- **CSS Variables** — тёмная/светлая тема
- **LocalStorage API** — сохранение прогресса пользователя

## ✨ Функционал

- 📚 **Каталог тем** — 15 тем по грамматике (времена, части речи, предложения)
- 🔍 **Фильтрация и поиск** — по уровню A1–B2, категориям и тексту
- 📝 **3 типа упражнений** — Multiple Choice, Fill in the Blanks, True/False
- 📊 **Прогресс** — сохраняется в localStorage, отображается на каждой странице
- 🌙 **Тёмная тема** — переключатель в шапке
- 📱 **Адаптивный дизайн** — работает на мобильных устройствах
